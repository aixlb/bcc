# 包拆拆 / XLB Storyboard 需求文档

> 适用版本：0.4.0
> 本文件随每次版本合并更新，记录当前版本已交付的需求与约束。

## 1. 总体目标

源码组织为桌面版 `apps/bcc-desktop`、CLI `apps/bcc-cli`、共用核心 `packages/bcc-core` 和 Agent skill `skills/bcc`，统一在公开 MIT 仓库 `aixlb/bcc` 维护。DSH 插件保留独立公开 MIT 仓库 `aixlb/dsh-bcc`。历史应用标识、数据位置和 npm CLI 包名保持兼容，详见 [MIGRATION.md](MIGRATION.md)。

把一段视频自动拆成可用于创作复盘的**剧本**与**分镜**，并支持导出为通用格式（Word / Excel / 可交互网页）。自 0.2.0 起，核心能力对外暴露为**命令行**与**桌面 GUI** 两种等价入口，二者共用同一套业务核心。

## 2. 已交付需求

### 2.1 剧本生成
- 输入视频，调用所选 provider 生成带 `[HH:MM:SS]` 时间码的场景化剧本。
- 剧本可编辑、可与视频同步预览。

### 2.2 分镜生成
- 自动检测镜头切点，先落「截图 + 时间」占位，AI 异步补全镜头要素（景别 / 角度 / 运镜 / 七段式提示词描述 / 台词 / 音效）。
- AI 识别完成后，可在帧差异曲线上查询、新增、移动和删除切点；首帧切点锁定，人工切割不受 0.4 秒最短间隔限制。
- 人工切点通过项目 sidecar 持久化，重新切割或切换切割方式后继续生效；移动切点时保留人工编辑过的右镜内容，只有显式重新识别才覆盖。

### 2.3 导出
- **剧本 → Word（.docx）**、**分镜 → Excel（.xlsx，含关键帧）**。
- **剧本 + 分镜 → 单文件 HTML（.html）**，要求：
  - 自包含、离线可用：关键帧（含为剧本按场景时间码抓取的帧）以 base64 内嵌，不依赖外部文件 / 网络。
  - 剧本视图：时码脊导航、滚动高亮、对白 / 动作 / 字幕分级排版、场景截图灯箱。
  - 分镜视图：卡片 / 表格两种形式；表格固定列宽、以「提示词描述」为主，时码竖排；关键帧灯箱。
  - 标题卡展示源视频参数（分辨率 / 帧率 / 码率 / 编码 / 体积 / 时长 / 场景数 / 镜头数）。
  - 搜索、深 / 浅主题切换并记忆、打印 / PDF、响应式、`prefers-reduced-motion`。
  - 页脚附「包拆拆用户手册」外链。

### 2.4 导入
- 支持导入已有剧本（`.md`）或分镜目录为项目。

### 2.5 命令行（CLI · bcc，0.2.0 新增）
- 纯 Node 实现，不依赖 Electron 运行；与 GUI **共用同一份 `config.yaml` 与项目库**。
- 子命令：`config`（设置读写 + 连接测试）/ `script`（拆剧本）/ `storyboard`（拆分镜）/ `research`（风格研究）。
- 输入兼收**视频路径**与**已存在 projectId**；研究支持多视频、`--input-dir` 扫目录、`--project` 复用。
- 输出按**扩展名推断**为主、`--format` 批量为辅：剧本 docx/md/txt/html、分镜 xlsx/html、研究 md/txt。
- 数据根优先级：`--data-dir` > `BCC_DATA_DIR` > 当前目录（含 `config.yaml`）> 平台 userData（与安装版共用）。
- 进度走 stderr、产物路径走 stdout；代理用显式配置或 `HTTPS_PROXY`（无系统代理自动探测）。

## 3. 非功能性约束
- 内置 ffmpeg / ffprobe，免用户额外安装。
- 打包版（含 Windows portable）配置 / 数据需跨重启持久化；目标目录不可写时回退到用户数据目录。
- macOS 应用图标（dock / 任务栏）需稳定显示品牌猫脸图标。
- 导出 HTML 内嵌的客户端脚本不得依赖任何外部资源（离线场景）。
- **业务核心须与框架解耦**：剧本 / 分镜 / 研究三条管线为纯入口，不依赖 Electron / React，可在纯 Node 与单元测试下运行；GUI 与 CLI 均为薄适配层。
- 核心入口须有单元测试覆盖（`npm test`，vitest）。
