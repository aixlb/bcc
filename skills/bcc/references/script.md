# 拆剧本详细规范（执行「拆剧本」任务前必读）

> 加载时机：用户要求「拆剧本 / 剧本 / 台词 / 对白」时，先完整读本文件，再开始任务。本规范优先于任何其他材料（包括大师方法论）；方法论只作分析深度参考。

## 目标与优先级

把视频转写成**完整、忠实、可直接使用的剧本**。三原则，按优先级：

1. **完整性 > 文采**：每一句台词、每一个场景都不能漏；宁可朴素，不可遗漏。
2. **忠实 > 润色**：台词照实转写，不概括、不缩写、不"大意是……"。
3. **具体 > 笼统**：画面描述写清楚"谁、在哪、做什么、镜头怎么动"，禁止"众人交谈""场景混乱"这类空话。

## 质量铁律（违反任何一条即不合格，交付前必须自查）

- **台词全覆盖**：视频里出现的每一句人声都转写，包括背景对话、喊叫、语气词、画外音（VO）、电话里的声音。听不清的写 `【听不清】`，**不得跳过、不得用省略号带过**。
- **场景全覆盖**：从 0 秒到视频结束，时间轴连续、无缺口；每个场景都要有 `[时间戳]` 头部。
- **体量达标**：对白为主的视频，剧本参考 **1 分钟 ≈ 300~600 字**。例如 10 分钟视频应在 **3000 字以上**（含台词与画面描述）。若成品明显低于此量级，说明遗漏了内容，**必须回头补看补写，不得交付**。
- **时间戳准确**：场景头的时间戳是该场景在视频中的实际开始时间；用 `bcc shots <视频> --no-frames` 拿到的镜头边界校准。

## 工作流（必须按步骤执行，这是防遗漏的关键）

### 第 1 步：准备（可选）

```bash
node "$BCC" probe <视频>            # 拿时长、分辨率，心里有数即可
```

有大师经验时，先取方法论作为分析框架（**本规范优先于方法论**）：

```bash
node "$BCC" master shanzhiyin --kind script > master-method.md
```

### 第 2 步：完整观看原视频（一次看完）

把**整个视频作为输入完整观看一遍**，从头看到尾，不要跳过任何部分。观看时：

- 记住每个场景的**起始时间戳**（场景切换处的时间）；
- 记住台词要点与说话人。

### 第 3 步：写剧本 md（格式见下）

看完后一次性写出完整剧本：每个场景 `[时间戳]` 头部 + `△ 画面描述` + **逐句台词**。

- **逐句转写台词**（人名：台词），多人对话不合并、不省略；
- 字幕、闪回、转场用 `【字幕…】` `【闪回】` 标注；
- 画外音标 `(VO)`：`张三（VO）：…`；内心独白用 `(OS)`。

### 第 4 步：自查（逐条核对，不合格就重看补写）

- [ ] 抽查任意两处重看一遍，确认没有漏句、漏场景；
- [ ] 场景时间戳递增、无缺口、与视频总时长对应；
- [ ] 字数达到体量参考（不足 → 重看补写，不得交付）；
- [ ] 每句台词都有说话人；听不清的都标了 `【听不清】`；
- [ ] 格式符合下方规范。

### 第 5 步：组装成品

```bash
node "$BCC" export script --from <剧本.md> --out <剧本.docx> --format docx,md,html --video <视频>
```

## 剧本 md 格式

每个场景头行 = `[时间戳] 编号 地点 时间`，随后是画面描述与对白：

```
[00:00] 1-1 办公室 日/内
△ 镜头从电脑屏幕缓缓摇到主角，他皱着眉点开邮件
张三：这个方案怎么又被退了？
李四（画外）：经理说预算超了。
张三：超了多少？
李四（VO）：百分之三十。

[00:15] 1-2 会议室 日/内
【字幕】三小时后
△ 投影仪亮起，张三站在幕布前
经理：这个季度必须砍掉百分之三十的预算。
```

规则：

- 时间戳支持 `[HH:MM:SS]` / `[MM:SS]` / `【HH:MM:SS】` / `(MM:SS)`；
- `△` 开头 = 画面/镜头描述行；
- `【字幕…】` = 字幕；`【闪回】`/`【梦境】` 等标注直接写在行首；
- `人名：台词` = 对白；画外音/独白用 `人名（VO）：` / `人名（OS）：`；
- 同一场景内不换行写多句台词，每人一句一行，保持时间顺序；
- 场景编号 `1-1` 形式（集-场），依次递增。
