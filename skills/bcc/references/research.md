# 风格研究详细规范（执行「风格研究」任务前必读）

> 加载时机：用户提供**多条视频**并要求「风格 / 调性 / 统一指南 / 参考」时，先完整读本文件再开始。

## 目标

从多部视频中提炼**可复用的风格配方**，产出一份《风格指南》md——它应能让一个新人照抄着拍出同风格的内容。

## 工作流

### 第 1 步：为每条视频切镜 + 关键帧（供逐镜比对）

```bash
node "$BCC" shots <视频1> --frames-dir <工作目录>/frames_1
node "$BCC" shots <视频2> --frames-dir <工作目录>/frames_2
# ……
```

（只要时间轴、不要图时用 `--no-frames`；但关键帧是风格比对的最好素材，建议保留。）

### 第 2 步：逐条观看原视频（核心）

模型具备原生视频能力（如 K3）时，**直接完整观看每条视频**，边看边记录风格要素。只支持看图的模型则逐镜看关键帧归纳。

### 第 3 步：写《风格指南》md（成品就是它，无需再组装）

建议结构（按实际素材取舍，不要求全有）：

1. **整体印象**：一句话概括这类视频的气质（如"高对比冷调、快节奏硬切、运动镜头为主"）。
2. **镜头语言**：常用景别（特写多还是全景多）、角度习惯、运镜偏好（手持/推拉/摇移）、镜头时长节奏（快切/长镜头）。
3. **剪辑手法**：转场方式（硬切/叠化/白闪）、节奏密度、音画配合。
4. **光线与色彩**：色调倾向、光影风格、调色特点（具体到色相/对比度）。
5. **声音风格**：BGM 类型、音效使用习惯、人声处理。
6. **叙事结构**：开场方式、节奏曲线、情绪走向。
7. **可复用配方**（重点）：把以上归纳成可直接执行的拍摄/剪辑清单，例如"开场 3 秒内必须出现一次硬切+重音"。

**每条结论都要有具体镜头佐证**：标注来自哪条视频的什么时间（如「视频A 00:12 的仰拍特写」），禁止空泛结论。

### 第 4 步：自查

- [ ] 每条视频都完整看过（不是只看关键帧）；
- [ ] 每条风格结论都有时间戳佐证；
- [ ] 「可复用配方」部分可执行（非形容词堆砌）。
