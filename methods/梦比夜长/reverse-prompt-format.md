# 反推提示词示例格式（内部武器库）

> **使用原则：** 本格式用于把一个镜头（或分镜设计）反推成可直接喂给 AI 文/图生视频工具（即梦 / 可灵 / Vidu / 海螺等）的单镜头提示词。整条提示词是**一段连续的自然语言**，不用标题、不用列表、不用编号——但内部严格遵循下面的十个区块与先后顺序。

---

## 一、结构总览：十个区块，顺序固定

| 序 | 区块 | 一句话职责 |
|----|------|-----------|
| ① | `[STYLE LOCK]` 风格锁 | 导演美学 + 写实质感 + 画幅 + 场景统一调色，全局定调 |
| ② | 图片锚定 | 每张参考图一行，声明它锚定什么（环境 / 道具 / 角色） |
| ③ | 主体一致性锁 | 主角当前形态的外观清单 +「严格保持一致」+ 相对比例 |
| ④ | 音轨 | 总原则（BGM/对话有无）+ 分层声音设计，逐一对应画面动作 |
| ⑤ | 运镜总述 | 「这是一个……镜头」：机位 / 焦段 / 景别 / 景深 / 速率 |
| ⑥ | 开场 | 起始构图（常为空镜）+ 明确时长 |
| ⑦ | 核心动作 | 主体入画 + 镜头运动 vs 主体反向运动 + 光线事件与触发时机 |
| ⑧ | 尾帧 | 收束构图 + 冲突元素入场 +「保持动态、绝不凝固」的运动清单 |
| ⑨ | 质感负面 | 绝非动画 / 3D / CG / 游戏引擎 / 卡通，排廉价光效 |
| ⑩ | 文字负面 | 排文字 / 字幕 / 水印 / UI / 图标 |

从全局到局部、从静态设定到时间轴、最后负面收尾。①–④ 是「设定区」（这个世界是什么样），⑤–⑧ 是「时间轴区」（这条镜头怎么演进），⑨–⑩ 是「负面区」。

---

## 二、逐区块规范

### ① [STYLE LOCK] 风格锁

固定以字面 `[STYLE LOCK]` 开头，一段话内依次给足五件事：

1. **镜头美学定调**：点名导演/流派 + 把该美学拆成具体镜头语言（不能只丢名字）。
   > 迈克尔·贝（Michael Bay）式的英雄环绕镜头美学（Bayhem hero shot）——低机位、长焦特写环绕、英雄光线、轻微升格、强烈对比与热点高光。
2. **写实质感锁**（对抗 AI 出图的动画倾向，词组堆叠）：
   > 完全写实的真人实拍电影质感、真实演员的皮肤毛孔与发丝肌理、纪实摄影感、IMAX 电影级画质、ARRI ALEXA 摄影机、Kodak Vision3 500T 胶片、真实电影颗粒。
3. **第二美学参照**（可选，用于叠加一种空间/情绪气质）：
   > Denis Villeneuve《沙丘》式的巨物压迫感美学。
4. **画幅**：`画幅 2.39:1。`
5. **场景与统一调色**：地点一句话 + 统一色调与饱和 + 大气粒子 + 空间感。
   > 崩塌的丝路部落沙丘废墟，《沙丘》式统一的暖沙土金与赭红调、低饱和、漫天沙尘尘雾弥漫、土褐崖壁与酒红破败帐篷、苍茫宏大纵深。

### ② 图片锚定

每张参考图**独立一行**，格式：`图片N　作为〈对象〉的（环境/视觉/形象视觉）锚定。`
排序按「环境 → 道具 → 角色/生物」；编号沿用上传顺序，不必连续。

### ③ 主体一致性锁

格式：`〈主体名+形态〉的形象（严格保持一致）：〈发型发饰〉；〈身形〉；〈服装配色总括——具体款式与细节〉。`
- 「严格保持一致」是固定咒语，不省略。
- 服装先给配色总括（如「黑红配色破败机能风」）再展开单品。
- 末尾**必带相对比例**，把主体和图片锚里的巨物勾在一起：
  > 她的身形相对于巨剑与兽王显得格外娇小。

### ④ 音轨

固定以 `音轨：` 开头。三层结构：

1. **总原则**先行：`仅环境音与动作音，不配 BGM，不要对话。`（有无 BGM/对话按项目调整，但必须显式声明）
2. **分层对应**：底层持续环境声 →「〈动作〉时是〈拟音〉」逐一对应时间轴里的每个动作节拍 → 高潮声效单独渲染（给足形容词权重）。
3. **贯穿声**收尾：`全程〈某声音〉贯穿。`

声音节拍必须与 ⑥⑦⑧ 的画面节拍一一对得上——写完时间轴后回头核对。

### ⑤ 运镜总述

固定句式 `这是一个〈镜头类型〉，` 然后一口气给全技术参数：机位（低机位仰拍）、焦段（长焦）、景别与取景对象（紧紧框住谁的哪个部位）、景深（浅景深）、空间压缩、速率（轻微升格——**并说明程度**：「略微放慢、更显戏剧性而非爬行慢镜」）、背景处理（虚化、高速流过）。

### ⑥ 开场

起始构图，常为**空镜**（主体不在画内，为入画做铺垫），描述完毕给明确时长：`持续约一秒。`
整条提示词只有开场给绝对时长，后面全靠节奏词（随即、一气呵成、恰好、此刻）驱动。

### ⑦ 核心动作

一条镜头的戏眼，用 `随即是……，一气呵成：` 引入。三个必备要素：

1. **主体入画方式**：不是凭空出现，而是有物理逻辑的入画（从画面下缘之外起身升入画面），并解释这个逻辑（她本蹲伏在镜头前方低处）。
2. **反向运动张力**（梦比夜长式核心技巧）：镜头运动方向与主体运动方向**相反**，并把这一点显式写给模型：
   > 镜头以低机位沿圆形轨迹匀速地从左向右环绕，而丹眉与镜头反方向地、从右向左缓缓转身（人物的旋转方向与镜头的环绕方向相反，形成迈克尔·贝式的强烈张力）。
3. **光线事件**：光不是静态设定，而是时间轴上的事件——给触发时机 + 光的来向 + 落在主体上的效果 + 情绪判词：
   > 当她转身转到一半的关键角度时——一道炽烈的英雄光线恰好从她侧后方打来、扫过并照亮她的脸……英雄感与张力在这一刻达到顶点。

### ⑧ 尾帧

用 `镜头环绕收束、运镜停定到尾帧构图并保持动态：` 引入。三件事：

1. **收束构图**：给构图判词（极端对角线构图、极端低角度大仰拍、画面强烈倾斜）+ 主体在构图中的姿态。
2. **冲突元素入场**：对手/威胁以什么方式压进画面 + 体型对比再次强调（悬殊到极致）。
3. **持续动态清单**（对抗 AI 视频结尾冻结的通病，必写）：显式声明「抵达尾帧构图后画面持续保持动态、绝不凝固成静止」，然后**列举**持续运动的元素——粒子（沙尘翻腾）、毛发（短发与发饰吹起）、衣物（内衬与流苏翻飞）、对手（持续逼近咆哮）——收一句总括（整个画面到最后一刻都是流动的、张力满溢的）。

### ⑨ 质感负面

固定句式，正面重申 + 连环否定：

> 全片为完全写实的真人实拍电影摄影质感、真实演员与真实〈道具材质〉的质感，绝非动画、绝非 3D 渲染、绝非 CG 塑料感、绝非游戏引擎画面、绝非卡通，避免一切廉价光效。

### ⑩ 文字负面

固定收尾句：

> 画面中不出现任何文字、英文、字幕、签名、水印、UI、图标、电量、时间。

## 三、写作要诀

1. **三层一致性锚，从大到小**：风格锁（全局气质）→ 图片锚（视觉资产）→ 角色锁（主体细节）。三层各管一段，不混写。
2. **关键设定至少出现两次**：体型对比在 ③ 和 ⑧ 各强调一次；写实质感在 ① 和 ⑨ 各锁一次；沙尘在 ①④⑥⑧ 反复出现。重要的事在不同区块换措辞重申，是对抗模型遗忘的主要手段。
3. **光线是事件不是参数**：把打光写进时间轴（何时、从哪来、扫过什么、达到什么情绪），而非静态罗列「逆光、轮廓光」。
4. **运动永远成对出现**：镜头动 + 主体动，且方向相反制造张力；背景则用浅景深虚化 + 高速流过来强化主体运动感。
5. **速率要给参照系**：不写光秃秃的「慢动作」，写「轻微的升格慢动作（略微放慢、更显戏剧性而非爬行慢镜）」「子弹时间般的轻微升格」——告诉模型慢到什么程度、不要慢成什么样。
6. **括号是给模型的导演注解**：解释意图（形成迈克尔·贝式的强烈张力）、澄清歧义（在长焦画面的下缘之外），随手用。
7. **声画同源**：音轨里的每个声音节拍必须能在时间轴区找到对应画面动作，反之高潮动作必有声音渲染。
8. **负面永远压尾**，且质感负面与文字负面分成两句，不合并。

音轨：仅环境音与动作音，不配 BGM，不要对话。底层是旷野狂风呼啸与崩塌部落的低频轰鸣；丹眉扛剑入画与转身时是沉重巨剑压上肩头的金属闷响、青铜管线的咯吱、脚步碾过碎石的踏响；环绕到位时风声拔高、沙尘呼啸；最后兽王冲来时是震彻天地、低频炸裂的巨兽咆哮怒吼，伴随它沉重踏地的轰隆与扬尘的轰鸣，咆哮的气浪感压满整个收尾。全程狂风卷沙的簌簌呼啸贯穿。
这是一个迈克尔·贝式的英雄环绕镜头，全程低机位仰拍、长焦特写镜头（紧紧框住丹眉的脸与肩扛巨剑的上半身、浅景深）、长焦压缩空间，带轻微的升格慢动作（略微放慢、更显戏剧性而非爬行慢镜），背景的部落废墟与沙尘在长焦浅景深里大幅虚化、高速流过。
开场是一个低机位长焦的空镜：低角度的长焦镜头朝前方望去、对着崩塌部落废墟的纵深——远处的土褐崖壁、酒红破帐、崩塌残骸在长焦浅景深里被压缩、虚化，狂风卷着沙尘成片地在画面里横向翻腾流过，暖沙赭红的天光，宏大而苍凉。此时画面下方是空的、没有人。持续约一秒。
